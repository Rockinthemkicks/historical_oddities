# Historical Oddities — Style Bible (FIXED, reused every video)

This file defines the parts of the visual style that must stay **identical**
across every video. It is not topic-specific — do not add characters, props,
or a specific era/setting here. When starting Stage 3 for a new video, read
this file first, then build that video's reference sheet by adding only the
per-topic sections (characters, props/vehicles, topic palette accents) on top
of what's fixed below.

## Rendering technique (never varies)
- Hand-drawn ink outline, bold and slightly imperfect/wobbly, but kept THICK
  and SIMPLE — not fine, not detailed, not scratchy
- Ink outline color is flat black or a single dark neutral gray — never
  brown, sepia, or charcoal-brown. The outline color itself must not carry
  any warm/brown tint
- Flat, clearly-bounded color blocking only. No cross-hatching, no fine
  linework shading, no gradients, no rendering of texture/material detail.
  Every shape should read as a single flat color
- Minimal internal detail everywhere — characters, props, and backgrounds
  should each be built from a small number of large simple shapes, not many
  small ones. If a detail doesn't help read the shape at a glance, cut it
- No paper texture of any kind — not "cream," not "warm," not "aged," not
  "notebook," not "parchment." The background/canvas is flat and textureless
- Clean, flat light background (bright off-white or one flat clean color) —
  not textured, not tan/cream, not warm/aged in tone
- No photorealism. No modern elements bleeding into a period setting.
  No graphic/violent content.
- When Stage 4 writes CHAT.IMG batch prompts, follow the "IMAGE-PROMPT
  PHRASING TO AVOID GENERATION FAILURES" rules in pipeline_prompt.md
  (non-graphic framing stated up front and matched to the video's actual
  tone, no conflict-coded words like "standoff"/"aftermath", no
  unnecessary negation lists, ASCII-only punctuation in any rendered
  on-image text) — this is a wording issue, not a change to the visual
  style itself.

## Character & prop design rules (never varies)
- Bold, rounded, exaggerated cartoon proportions (oversized heads, big
  expressive eyes, bouncy poses) — lean toward animated-show character
  design, not historical illustration
- Strong, readable silhouettes — a character should be identifiable in
  silhouette alone
- Storyboard-friendly: characters drawn in clear, neutral reference poses
  (standing, 3/4 or profile), not mid-action
- "Animation-ready": clean enough shapes that the same character reads
  consistently if redrawn across many scene images

## Color palette (fixed family, topic sets the accents)
- Base family: bright, saturated cartoon colors — not muted/earthy. Think
  modern animated-series palette: clear blues, reds, greens, yellows, with
  browns/tans used only where the subject itself is brown (wood, dirt,
  leather), not as the overall color wash of the whole image
- One or two topic-specific accent colors are allowed per video, layered on
  top of this bright base
- No sepia-tone or monochrome-brown wash over the whole scene
- Do NOT describe the overall palette with words like "earthy," "warm
  parchment," "ochre-toned," "muted," "sepia," "soot," "cream," or
  "restrained" — those describe an aged/historical illustration look, which
  is the opposite of this fixed bright-cartoon palette, even for period-set
  or somber topics. A 1930s setting, or a genuinely tragic topic, still gets
  the same bright base palette; only the props/costumes should be
  period-accurate, not the overall color mood of the image. A topic whose
  real-world subject is itself yellow-gray or smoky (e.g. smog) can use that
  as one of its 1-2 permitted accent colors, but it must not also recolor
  the paper, ink, or overall wash to match — the rest of the image stays on
  the fixed bright base

## Reference sheet layout (use this structure every time)
When generating a new master reference / style-anchor sheet for a video,
lay it out in these sections, same as always:
1. **Characters** — each recurring character/figure for this topic, labeled
2. **Color Palette** — swatches, base family + this video's accent(s)
3. **Line & Texture** — a small sample strip showing the ink line only
   (flat black/dark-neutral, no cross-hatch, no paper texture — this
   section's *content* is identical every video)
4. **Props & Vehicles** — topic-specific objects/vehicles, labeled
5. **Style Overview** — bullet list restating the fixed rules above, plus
   any topic-specific setting notes (era, location)
6. **Composition Notes** — 4 small panel sketches showing: wide establishing
   shot, explanatory/cause-effect shot, exaggerated/myth-busting shot,
   transition/resolution shot

## What's allowed to change per video
- The characters, creatures, props, vehicles themselves
- The specific era/setting named in the Style Overview box
- 1-2 accent colors layered onto the fixed base palette
- The specific scene content in the Composition Notes panels

## What must never change
- Line technique (flat black/dark-neutral ink, thick and simple, no
  cross-hatch), flat textureless background, bright cartoon base palette,
  exaggerated proportions/silhouette rules, "no photorealism" constraint,
  and the 6-section sheet layout itself
